# @mosaic/design-tokens

Colour, Liquid Glass, type and motion tokens approved at Gate 1 on 2026-11-19, with the indigo accent. The approved design previews are in `design/`. Any later deviation from them is recorded in `docs/decision-log.md`.

Exports `themes` (light and dark), `accent`, `glass`, `type` and `motion`. The web app generates its CSS custom properties from these. Light is the default theme, and dark is a separate palette rather than an inversion.
