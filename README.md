# Mosaic

Protect the information you never realized you were revealing.

Mosaic is a privacy-first publication review workspace for the Google #BuildHybridAI 2026 hackathon. It checks how a new draft and earlier releases combine to reveal context, using on-device analysis for private material and cloud-generated generic test packs through Firebase AI Logic.

## Status

**Phase 0: design approval.** The repository currently holds only the design previews (`design/`) and the decision log (`docs/decision-log.md`). The application has not been built yet, and nothing here should be read as a claim about working software.
